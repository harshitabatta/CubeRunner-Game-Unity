# Cube Runner 🎮

A simple arcade-style 3D game developed using Unity, where players control a cube, navigate through obstacles, and try to survive for as long as possible.

## About the Game

Cube Runner is a casual arcade game focused on reflexes, timing, and obstacle avoidance. The objective is to navigate through the game environment, avoid obstacles, and achieve the highest possible score.

Developed as a personal game development project using Unity.

## Gameplay

- Control a cube through an obstacle-filled environment.
- Avoid collisions with obstacles.
- Survive as long as possible.
- Challenge yourself to beat your high score.

## Tech Stack

- **Game Engine:** Unity
- **Platform:** Android
- **Build:** APK

## Installation

1. Download the APK from this repository.
2. Transfer it to your Android device.
3. Enable installation from unknown sources if prompted.
4. Install and launch the game.
